# Implementation and acceptance status

23 October 2026. The expanded private-beta implementation is in the checkout. Public launch still depends on credentials, hosting and live acceptance. Feature count is not a production-readiness percentage.

The first phone beta includes one-click, server-selected seven-day number assignment from approved owned stock or optional budget-capped Twilio rental, a maximum 20-day operator pool, default 3×60-second calls per workspace, provider balance/expiry pauses, email retry and a responsive allowance/test-call UI. Purchases default off; uncertain results are reconciled without a second purchase. Explicit replacement preserves original expiry/usage and old callback bindings. It is disabled until configured and live-tested. See [operator setup and remaining launch needs](PHONE_TRIALS.md). The additive schema is now 64 tables, revision `2026-10-23-website-assistants`; production still performs no startup DDL.

See [website assistant behavior, setup and coverage limits](WEBSITE_ASSISTANTS.md). Latest isolated verification: 288 passed, 2 skipped; production web build, preview/OAuth/beta browsers and restricted PostgreSQL64 upgrade/concurrent refresh and booking checks passed. Earlier independent-origin website/embed checks remain recorded in VERIFICATION. Real reference-site/provider/public deployment acceptance remains pending.
